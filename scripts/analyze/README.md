# 상권 분석

`data/raw/` 의 분기 스냅샷을 비교해 대구 업종별 소멸률과 권장 연동률을 산출한다.

## 쓰는 법

1. https://www.data.go.kr/data/15083033/fileData.do 하단 **"주기성 과거 데이터"** 탭에서
   서로 다른 분기 CSV를 2개 이상 받는다 (권장: `20250630`, `20251231`, `20260331`).
   **data.go.kr 로그인이 필요하다.**
2. 받은 파일을 `data/raw/` 에 그대로 넣는다. **파일명에 `YYYYMMDD` 기준일이 들어 있어야** 한다.
3. 실행

```bash
node scripts/analyze/build-market.js
```

결과는 `web/public/market.json` 에 쓰인다.

## 환경변수

| 이름 | 기본값 | 설명 |
|---|---|---|
| `REGION` | `대구광역시` | 시도명 필터 |
| `MIN_COUNT` | `30` | 이보다 표본이 적은 업종/상권은 제외 (비율이 튄다) |

## 산출 방식

- **소멸률** = 첫 스냅샷에 있던 상가업소번호 중 마지막 스냅샷에서 사라진 비율
- **연 잔존율** = (1 − 소멸률) 을 기간 개월수로 연율화
- **권장 기본료 비중** — 연 잔존율 0.60~0.95 구간을 기본료 비중 0.25~0.65 로 선형 사상한다.
  ```
  t = clamp((연잔존율 - 0.60) / 0.35, 0, 1)
  기본료 비중 = 0.25 + 0.40 × t
  ```
  생존율이 높은 안정 업종은 기본료 비중을 올리고, 변동이 큰 업종은 낮춰
  임차인의 고정비 부담을 줄인다. 나머지가 매출 연동분이 된다.
  구간을 0.60~0.95 로 잡은 이유는 실제 업종 잔존율이 대부분 그 안에 몰려 있어서다.
  단순히 잔존율에 비례시키면 업종 간 차이가 거의 드러나지 않는다.

## 반드시 알아둘 한계

이 데이터에는 **공식 폐업 플래그가 없다.** "직전 스냅샷에 있던 상가업소번호가 사라졌다"를
소멸로 **추정**할 뿐이고, 실제로는 이전·상호변경·휴업일 수 있다.
제안요약서와 발표에서 이 한계를 먼저 밝히는 편이 신뢰를 얻는다.
