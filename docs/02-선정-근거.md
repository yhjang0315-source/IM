# 선정 근거

## 두 개의 필터

1. **블록체인 필연성** — "블록체인 빼고 DB로 만들면 무엇이 망가지는가"에 한 문장으로 답할 것.
   ①서로 신뢰 안 하는 다자가 같은 기록을 봐야 함 ②사후 감사 대신 사전 강제 ③제3자가 원본 없이 검증
2. **대구 유독성** — 문제를 설명하는 문장에 **전국 순위**가 들어갈 것.
   안 들어가면 서울에서 내도 되는 아이디어다.

## 탈락한 후보와 이유

| 후보 | 이유 |
|---|---|
| 선결제 안심 에스크로 | 전국 문제 + 대구 삽화. 대구 체육시설 피해구제는 오히려 감소 중(171→109→86건) |
| 목적잠금형 바우처 지갑 | 시장 공약과는 맞으나 문제(급식카드 오남용)는 전국 단위. 대구 순위 근거 없음 |
| 가족 공동승인 시니어 지갑 | 구현은 가장 작으나 대구 고령화율이 특·광역시 1위가 아님 |
| 지역화폐 부정유통 방지 | 서울·경기·부산이 이미 FDS 운영 중. 블록체인 지역화폐는 2018~2020 시도 후 확산 실패 |
| 골목상권 폐업 조기경보 | 데이터는 최고지만 블록체인 필연성 없음 → 본안의 연동률 산출 모듈로 편입 |
| 예금토큰 결제망 | 한은·금결원이 이미 하는 일. 1~2인 데모는 "장난감" 인상 |

## 차점 후보 (1점 차)

**다중채권자 사적 채무조정** — 대구 개인회생·파산 전국 2위라 전국 4번째 회생법원이 대구에 개원.
회생 전 단계에서 채권자들이 죄수의 딜레마에 빠져 아무도 먼저 유예하지 못하는 구조라
블록체인 필연성은 오히려 더 강하다. 다만 추심 동결이 법적으로는 계약상 합의일 뿐이고
채권자 화면이 늘어나 14일 안에 여유가 사라진다. 보류.
