# 시연영상 대본

제출용 5분. 읽으면서 찍을 수 있게 **말할 문장을 그대로** 적었다.
화면 조작은 `→` 로, 하지 말아야 할 것은 ⚠ 로 표시했다.

전체 예산 **4분 40초**. 5분을 넘기면 뒤가 잘리므로 여유를 20초 남긴다.

---

## 찍기 전에

```bash
npm run chain                 # 1번 터미널
npm run deploy                # 2번 터미널 — 미체결 상태로 시작해야 한다
npm --prefix web run dev      # 3번 터미널
```

- [ ] 브라우저 창을 **1280×800** 으로 맞춘다. 그보다 작으면 표가 접힌다
- [ ] 브라우저 확대는 **100%**. 북마크바를 숨긴다
- [ ] 터미널 창은 화면에서 치운다. 개발 중인 화면처럼 보이면 손해다
- [ ] 새로고침해서 **미확정 — 계약 탭에서 체결** 이 헤더에 보이는지 확인
- [ ] 마이크로 한 번 시험 녹음. 방 울림이 있으면 자막으로 대체할 것

⚠ 브라우저 개발자도구를 열지 않는다. 데모 키가 콘솔에 보일 수 있다.

## 0:00 — 0:35 · 문제

> "대구 소규모 상가 공실률은 9.1%입니다. 17개 시도 중 1위입니다.
> 동성로는 23%, 서문시장 일대는 34%가 비어 있습니다.
>
> 그런데 임대료는 내려가지 않습니다. 임대인이 호가를 낮추면 담보가치가 함께 떨어지기 때문입니다.
> 임차인은 매출을 알 수 없는 상권에 고정 월세를 걸 수 없습니다.
> **양쪽 다 0원을 택하고 있습니다.**
>
> 답은 이미 있습니다. 매출에 연동하는 임대차. 백화점이 수십 년째 쓰는 방식입니다.
> 골목상권에 없는 이유는 하나입니다. **서로의 매출을 못 믿기 때문입니다.**"

→ 화면은 앱 첫 화면(계약 탭)에 그대로 둔다. 슬라이드를 따로 만들지 않는다.

## 0:35 — 1:30 · 계약을 만든다

> "임대인부터 시작합니다. 먼저 **무엇을 빌리는 계약인지**를 적습니다."

→ 목적물에 매장명·주소·면적·용도 입력. 아래 미리보기 문구가 조합되는 것을 보여준다

> "이 문구도 나중에 양측이 서명할 대상입니다. 확정된 뒤에는 주소 한 글자도 못 바꿉니다.
>
> 조건은 감으로 정하지 않습니다. 업종과 상권을 고르면 실제 데이터에서 나온 권장값이 뜹니다."

→ 업종 "카페", 상권 "중구 성내1동" 선택 → 권장값 카드가 뜨는 것을 잠깐 멈춰서 보여준다

> "이 상권의 카페 224개를 9개월 추적한 결과입니다. 연 잔존율 86%.
> 그래서 기본료를 37%, 매출 연동분을 63%로 권합니다."

→ "권장값 적용" 클릭 → 12개월 미리보기 → **임대인 서명**

> "임차인으로 넘어갑니다."

→ 역할 전환 → 조건이 잠긴 채 보이는 화면 → **임차인 서명** → **체인에 확정**

> "두 사람이 서명했고, 이제 조건은 컨트랙트에 박혔습니다.
> **조건을 바꾸는 함수 자체가 없습니다.** 임대인도, 저희도 못 바꿉니다."

→ 헤더가 "확정 · 변경 불가"로 바뀌는 것을 보여준다

## 1:30 — 2:20 · 매출은 은행이 쓴다

→ 임차인 탭 → 매출 슬라이더를 움직여 임대료가 따라 변하는 것을 보여준 뒤 **예치**

> "임차인이 다음 달 임대료를 미리 넣어 둡니다. 슬라이더를 내리면 하한에서 멈춥니다.
> 매출이 0이어도 임대인은 하한만큼은 받습니다.
>
> 이제 매출을 확정할 차례인데, **여기서 임차인은 아무것도 할 수 없습니다.**"

→ 게이트웨이로 전환 → 매출 게시

> "매출을 쓰는 것은 은행입니다. 임차인의 카드 정산을 이미 보고 있는 쪽이죠.
> 컨트랙트는 이 주소 외에는 게시 자체를 거부합니다.
> 임차인이 매출을 축소 신고할 방법이 구조적으로 없습니다."

→ 정산 → 원장에 지급이 찍히는 것

## 2:20 — 3:00 · 다투면 멈춘다

→ 임대인으로 전환 → 이의 제기

> "임대인이 이 숫자에 이의를 걸었습니다. **정산이 멈춥니다.**
> 이의는 게시 후 7일 안에만 가능하고, 그 기간이 지나면 컨트랙트가 거부합니다."

→ 임차인으로 전환 → 동의 → 재산정

> "양측이 동의하면 다시 흐릅니다. 끝내 합의가 안 되면 14일 뒤에
> **양측이 계약할 때 함께 서명해 지정한** 조정인만 개입할 수 있습니다.
> 은행은 조정인이 될 수 없습니다. 매출을 쓴 쪽이 분쟁까지 결정하면 안 되니까요."

## 3:00 — 4:00 · 이 영상의 핵심 장면

→ 명세서 탭 → 아래로 스크롤 → 증빙 대조

> "은행이 준 정산 원본이 진짜인지 어떻게 압니까.
> 체인에는 원본이 아니라 **해시만** 올라갑니다. 원본은 은행이 갖고 있습니다.
> 개인정보를 체인에 올리지 않으면서도 위변조를 잡아내기 위해서입니다.
>
> 원본을 여기 넣어 보겠습니다."

→ 정산 원본 문자열을 붙여넣기 → **일치** 표시

  붙여넣을 문자열은 **게이트웨이 탭의 매출 게시 칸에 그대로 떠 있다**
  (`IM-PG-SETTLE|<컨트랙트주소>|<회차>|<매출>|<시작월>`).
  찍기 전에 미리 복사해 두면 화면 전환 없이 붙여넣을 수 있다.

> "일치합니다. 그럼 한 글자만 바꿔 보겠습니다."

→ 숫자 하나 수정 → **일치하는 기록이 없습니다**

> "바로 드러납니다.
> 해시를 화면에 띄워 두는 것과, 그 해시로 실제 대조가 되는 것은 다릅니다.
> 저희가 만든 것은 매출연동 임대차라는 상품이 아니라, **이 대조가 가능한 인프라**입니다."

⚠ 이 구간은 다시 찍더라도 반드시 성공시킨다. 심사에서 가장 오래 기억되는 장면이다.

## 시간이 남으면 붙일 장면

우선순위 순. 5분을 넘기면서까지 넣지 않는다.

1. **자금이 묶이지 않는다** — 게시만 하고 정산하지 않은 달을 남긴 채 종료를 눌러 본다.
   "아직 처리 중인 달이 있습니다"로 막힌다. (15초)
2. **미납 상환** — 일부러 적게 예치한 달을 정산하면 미납이 찍히고, 임차인 탭에서 상환하면
   임대인에게 바로 간다. 계약이 끝나도 채무는 남는다. (20초)
3. **조정인** — `npm run demo:ff` 로 체인 시간을 15일 앞으로 돌린 뒤 조정인 역할로 전환.
   그때서야 버튼이 나타난다. (25초, 터미널이 화면에 나와야 해서 마지막 순위)
